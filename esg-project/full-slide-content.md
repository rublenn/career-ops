# HOW TO MAKE A 3D / INTERACTIVE PPT (Tools + Steps)

## Best tools, ranked for your case

### 1. Gamma.app — EASIEST + most modern (RECOMMENDED)
- AI builds the whole deck from a prompt in ~2 minutes.
- Cards animate/slide in, looks 3D-ish and very modern.
- Free tier works; export to PPT or PDF.
- **Steps:** gamma.app → "Create new" → "Paste in text" → paste this whole file → choose a theme → Generate → tweak → Export.

### 2. Prezi — TRUE 3D / zoom (most "wow", interactive)
- Camera zooms and rotates between topics — the classic "3D presentation" feel.
- Best if your professor likes interactivity.
- **Steps:** prezi.com → New Presentation → pick a zoomable template → drop each slide's content into a "topic" node → it auto-creates the zoom path.
- Downside: steeper learning curve, ~1 hour to set up well.

### 3. PowerPoint with Morph + 3D models (built-in, free if you have Office)
- **Morph transition** = smooth cinematic movement between slides (looks 3D/animated).
- Insert → 3D Models for rotating objects (e.g., a 3D globe for the ESG/environment theme).
- **Steps:** Build slides normally → put a slightly-moved copy of objects on the next slide → Transitions → **Morph**. For 3D: Insert → 3D Models → pick from library → it rotates on screen.

### 4. Beautiful.ai — smart auto-design
- Templates auto-arrange your content beautifully; less "3D", more polished.
- Good middle ground between Canva and Gamma.

### 5. Canva — safest, free, fast
- Tons of animated templates; "ESG" / "Sustainability" templates exist.
- Add motion: select element → Animate → choose effect. Export as PPT or MP4.

## My recommendation for you
**Gamma** for speed + modern look, OR **PowerPoint + Morph** if you want full control and that 3D animated feel. Use Prezi only if you have a free evening to learn it.
